## 📖 Overview

**Luxe POS** streamlines the intersection of guest services, dining, and financial management into a single, cohesive experience. Built for establishments like the Elegant Hotel, it combines a high‑end terminal interface with powerful backend capabilities to handle everything from room billing to inventory tracking – all in real time.

---

## ✨ Key Features

- **Unified Terminal Interface**  
  A high‑end, dark‑mode terminal for processing orders for both in‑room guests and outside visitors.

- **Advanced Room Billing**  
  Seamlessly manage room rates with integrated Advance Payment tracking and automated transaction recording.

- **Dynamic Inventory Management**  
  Effortlessly organize menu items across categories (Food, Beverage, Spa, etc.) with real‑time updates.

- **Intelligent Financial Insights**  
  Independent “Monthly Insights” dashboard featuring revenue analytics, best‑selling item tracking, and a dedicated high‑performance transaction scroller.

- **Premium Guest Documentation**  
  Automated generation of professional, high‑fidelity invoices and bill summaries using a unified premium template.

- **Real‑time Synchronization**  
  Powered by Firebase for instant data consistency across multiple terminals.

---

## 🛠️ Technology Stack

- **Frontend**  
  HTML5, Tailwind CSS (custom premium design system), Vanilla JavaScript

- **Backend**  
  Node.js, Express (storage & file management)

- **Database & Authentication**  
  Google Firebase Realtime Database & Firebase Authentication

- **Visuals & Icons**  
  Material Symbols, Inter typography, Glassmorphism UI patterns

---

## 🎨 Design Philosophy

The system is built with a **“Luxury First”** approach – utilizing glassmorphism, subtle micro‑animations, and a curated color palette to ensure the software matches the high‑end service of the establishment it serves.
